# Happy Birthday, Lei! 🎂

A simple, dependency-free birthday greeting website styled like a **flip book**.
Click the **Next** button (or use the arrow keys) to turn the pages with a
realistic page-turn animation.

## Files

- `index.html` — page structure and greeting content
- `styles.css` — book/page styling and the 3D page-flip transition
- `script.js` — page navigation and flip logic

## Run it

No build step or dependencies. Just open the site in a browser:

```bash
# option 1: open the file directly
open index.html            # macOS
xdg-open index.html        # Linux

# option 2: serve locally
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Controls

- **Next → / Prev ←** buttons
- **→ / ←** arrow keys
